Engkanto Siklaban Para sa Dugo ni Bathala

This project is a 2D fighting game inspired by Philippine mythology and folklore, featuring combat-oriented gameplay influenced by the mythical creatures and legendary beings found in traditional Filipino stories. The game combines cultural themes with interactive fighting mechanics, translating elements of Philippine mythology into playable characters, environments, and combat interactions. Its objective is to provide an engaging gameplay experience while introducing players to the diverse collection of mythical creatures and cultural narratives found in the Philippines.

My primary responsibility focused on the technical implementation of the game's core mechanics and gameplay systems. Using the Scratch platform, I designed and developed the underlying game logic, including player movement, directional controls, attack detection, collision-based damage calculation, health management, scoring systems, and game state transitions. I also implemented combat interactions between players, ensuring that attacks trigger appropriate damage responses and update the corresponding health values in real time.

The game logic was structured around event-driven programming and conditional systems to manage player inputs, combat states, hit detection, and win conditions. Physics-related mechanics such as movement behavior, directional interaction, and collision detection were integrated to create responsive character controls. Additionally, a game state management system was implemented to handle match progression, player defeat, scoring updates, and game-over conditions.

Through this project, I gained practical experience in game logic architecture, event-driven programming, collision detection, state management, gameplay physics, and interactive system design while applying Philippine cultural mythology as the conceptual foundation of the game.

Project View
