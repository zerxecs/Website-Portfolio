Apartment Rental Management System

This project is a web-based Apartment Rental Management System designed to digitalize the rental process between administrators, property owners, and tenants. The system allows property owners to manage apartments and rooms, while prospective tenants can browse available properties and submit rental applications online.

The backend was developed using the Laravel framework, following the Model-View-Controller (MVC) architectural pattern to separate business logic, data management, and application interfaces. Laravel routing and dynamic route parameters were implemented to handle resource-specific pages and operations using unique identifiers. The system also utilizes relational database relationships to connect users, apartments, rooms, tenants, payments, maintenance requests, and staff.

A major feature of the system is its role-based access control, providing different functionalities for Administrators, Property Owners, and Tenants. Administrators manage user accounts and application approvals, property owners manage their properties and tenants, while tenants can apply for rooms, submit maintenance requests, access support services, and monitor their rental payments. The project provided practical experience in Laravel development, MVC architecture, CRUD operations, authentication workflows, database relationships, and role-based system design.

Project View

  • Role-Based Management System

    The system provides dedicated dashboards and functionality based on user roles. Administrators manage account approvals and users, property owners manage apartments, rooms, tenants, and staff, while tenants can manage applications, maintenance requests, and rental payments.

  • Laravel MVC Architecture

    Developed the backend using Laravel and its MVC architecture. Models handle database relationships, Controllers manage business logic and application workflows, while Laravel routes connect HTTP requests to dynamic resource-specific pages and operations.

  • Relational Database Design

    Designed a relational database structure connecting users, landowner applications, apartments, rooms, tenants, payments, maintenance requests, room images, and staff. Foreign key relationships were implemented to maintain data consistency across the rental management workflow.

  • Rental Application Workflow

    Implemented a multi-stage application and approval workflow where landowners must first be approved by administrators before managing properties. Tenant applications are processed through administrator and property owner approval before an account becomes an active tenancy.
