Classiz

This project was developed as an educational quiz platform called Classiz, where instructors can create and manage classes, students, and quizzes. I was assigned as one of the backend developers, focusing on the server-side functionality and API that connects the application to the database.

My main responsibility was to develop and maintain the backend using Node.js, Express.js, and MongoDB with Mongoose. I implemented RESTful API endpoints for user authentication, class management, student management, and quiz management. I also implemented JWT-based authentication middleware to protect authorized routes and ensure that user requests were properly authenticated.

One of the more important parts of my contribution was designing the database structures for users, classes, students, and quizzes, as well as handling the communication between the frontend, backend, and database. I also tested the developed endpoints using Postman to verify that requests, authentication, data validation, and responses were working correctly. Working on Classiz gave me practical experience in backend development and helped me understand how APIs, authentication, databases, and frontend applications work together as one complete system.
