A CNN-LSTM Multi-Task Learning Approach for Polyphonic Guitar Chord Recognition

This project is my undergraduate thesis focused on Automatic Guitar Chord Recognition using a deep learning approach. The system was designed to identify guitar chords from polyphonic audio recordings by analyzing their harmonic and temporal characteristics.

The proposed model uses a hybrid CNN-LSTM Multi-Task Learning architecture that combines Constant-Q Transform (CQT) and Chroma features. Convolutional Neural Networks were used to extract meaningful frequency patterns from the audio, while Long Short-Term Memory (LSTM) layers were used to learn temporal relationships between consecutive musical frames.

Instead of predicting every chord as a single class, the model performs multi-task learning by independently predicting the chord root and chord quality. These predictions are combined to determine the final chord, allowing the system to better learn the musical structure of guitar chords. The final model achieved 82.02% Root Accuracy, 90.02% Quality Accuracy, and 78.13% Exact Chord Recognition Accuracy on the test dataset.

This research gave me hands-on experience in machine learning, deep learning, audio signal processing, dataset preprocessing, model evaluation, and GPU-based training. The project was developed using Python and modern machine learning libraries including TensorFlow, Librosa, NumPy, Pandas, and Scikit-learn.

Project View

  • CNN-LSTM Multi-Task Architecture

    Hybrid deep learning architecture that combines CQT and Chroma audio features using CNN layers for feature extraction and LSTM layers for temporal learning. The model independently predicts the chord root and quality through a multi-task learning approach.

  • Audio Feature Extraction

    Guitar audio recordings were transformed into CQT and Chroma representations to capture frequency, harmonic, and tonal information before being processed by the deep learning model.

  • Recognition Workflow

    End-to-end workflow showing how raw guitar audio is processed, transformed into audio features, analyzed by the CNN-LSTM model, and converted into predicted chord labels.

  • Model Performance

    Final evaluation results demonstrating strong performance in predicting chord roots and qualities, achieving 78.13% exact chord recognition accuracy on the test dataset.
