Game 1

This project was created during my course in Sports Elective with specializing in Game development. In this project I used Scratch as the tool to develop an educational game where the player will be ask multiple arithmetic questions and the player will have to answer. --picture 1 game title screen, picture 2 game play, picture 3 game over screen

To make this game into fruition I have planned everything from its concept down to its implementation. For instance I have first to make the concept feasable to the limitations of the scratch platform such as limitation of the number of sprites, the number of scripts, and the number of variables without compromising the game's quality and playability. Even with proper planning, the actual coding behind the scene were challenging so I have to meticolously check each block of codes and to lessen the legth of each block I have to create appropriate functions and algoritms to lessen the number of blocks and to make the code more readable. With that experience I have come to appreciate the relevance of each block of codes and how they are interconnected to each other and how they affect the overall game play.
